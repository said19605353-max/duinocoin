What this tool does

It automatically detects COM port changes on Windows.
If a port changes (for example, you plug an Arduino or USB hub into a different port), the system removes the old port entry and continues with the new one.

When you have 20 Arduino Nano devices, you don’t need to add each one manually.
The script automatically scans, selects, and registers all connected Arduinos.

This eliminates manual COM port management and makes large‑scale Arduino flashing much faster and more reliable.
